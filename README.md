# CIFAR-10 Computer Vision Classifier

A modular PyTorch implementation of convolutional neural network (CNN) architectures trained and evaluated on the CIFAR-10 dataset.

## Documentation & Experiments

For the complete technical documentation, architecture specifications, training pipelines, and detailed experimental results (EXP-01 through EXP-06), see:
👉 **[src/Readme.md](src/Readme.md)**

## Quick Start

### Installation
```bash
pip install -r requirements.txt
```

### Training
```bash
cd src
python train.py
```
